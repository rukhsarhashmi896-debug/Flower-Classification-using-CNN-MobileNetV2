# 🌸 Flower Classification using CNN & MobileNetV2

A Deep Learning project for classifying flower images into **5 different categories** using **Transfer Learning with MobileNetV2, TensorFlow, and Keras**.

## 🌸 Flower Categories

The model classifies flowers into the following five categories:

* 🌼 Daisy
* 🌻 Dandelion
* 🌹 Rose
* 🌻 Sunflower
* 🌷 Tulip

---

## 📌 Project Overview

Flower classification is an image classification problem where a Deep Learning model learns to identify the type of flower from an input image.

In this project, **MobileNetV2**, a pretrained Convolutional Neural Network (CNN), is used through **Transfer Learning**.

The pretrained MobileNetV2 model is used as a feature extractor, and additional layers are added for classifying the five flower categories.

The complete workflow includes:

**Dataset → Preprocessing → Data Augmentation → MobileNetV2 → Training → Evaluation → Prediction**

## 🧠 Why MobileNetV2?

MobileNetV2 is a lightweight and efficient CNN architecture.

It is suitable for image classification because:

* It is computationally efficient.
* It requires fewer parameters compared with many larger CNN architectures.
* It provides good image feature extraction.
* It is suitable for Transfer Learning.
* It can be useful for applications where computational resources are limited.

---

## 🔄 Transfer Learning

Instead of training a CNN model completely from scratch, this project uses the **MobileNetV2 model pretrained on ImageNet**.

The pretrained model has already learned useful visual features such as:

* Edges
* Shapes
* Textures
* Patterns
* Object features

The pretrained base model is used as a feature extractor, while new classification layers are added for the flower categories.

```python
base_model = MobileNetV2(
    weights="imagenet",
    include_top=False,
    input_shape=(224, 224, 3)
)
```

---

## 🖼️ Image Preprocessing

All images are resized to:

```text
224 × 224 × 3
```

The images are then preprocessed according to the requirements of MobileNetV2.

The dataset is converted into TensorFlow datasets for efficient training.

---

## 🔀 Data Augmentation

Data augmentation is applied to improve the model's ability to generalize to new images.

The project uses:

```python
data_augmentation = tf.keras.Sequential([
    tf.keras.layers.RandomFlip("horizontal"),
    tf.keras.layers.RandomRotation(0.1),
    tf.keras.layers.RandomZoom(0.1)
])
```

### Augmentation techniques used:

* Random Horizontal Flip
* Random Rotation
* Random Zoom

These transformations create slightly different versions of training images and can help reduce overfitting.

---

## 🏗️ Model Architecture

The final model consists of the following layers:

```text
Input Image
     ↓
Data Augmentation
     ↓
MobileNetV2
     ↓
GlobalAveragePooling2D
     ↓
Dense Layer (128 neurons)
     ↓
Dropout (0.3)
     ↓
Dense Layer (5 neurons)
     ↓
Softmax
     ↓
Flower Class Prediction
```

### Model Code

```python
model = Sequential([
    data_augmentation,
    base_model,
    GlobalAveragePooling2D(),
    Dense(128, activation="relu"),
    Dropout(0.3),
    Dense(5, activation="softmax")
])
```

---

## 📚 Important Layers

### GlobalAveragePooling2D

Converts the feature maps generated by MobileNetV2 into a compact feature representation before sending them to the Dense layer.

### Dense Layer

The Dense layer learns the important patterns required for classifying the flower images.

```python
Dense(128, activation="relu")
```

### Dropout

Dropout is used to reduce overfitting by randomly deactivating some neurons during training.

```python
Dropout(0.3)
```

### Softmax

The final Softmax layer produces probabilities for the five flower classes.

```python
Dense(5, activation="softmax")
```

The class with the highest probability is selected as the prediction.
